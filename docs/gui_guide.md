# 图形界面使用指南

适用于 `cfx_gui.py`（Version 2.0）。它只能在 Windows 上完成真实扫描，因为扫描需要 ANSYS CFX 和 PowerShell 7。

## 启动

在 Windows 下双击 `start_cfx_gui.bat`，或在命令行执行 `py -3 cfx_gui.py`。

启动脚本会依次尝试 `py`、`python`、`python3`；如果 PATH 里没有 Python，还会去这几个常见位置找：

- `%LocalAppData%\Programs\Python\Python*`
- `%ProgramFiles%\Python\Python*`
- `%ProgramFiles(x86)%\Python\Python*`

仍提示找不到 Python 时，先检查 Python 安装器里是否勾选了 `Add python.exe to PATH`，然后重新打开终端或重新双击。

## 第一次使用

1. 选择 **DEF** 文件和 **Base CCL** 文件（必填）。可选填一个 **RES** 文件作为初始流场。
2. 如果系统找不到 `cfx5solve` 或 `cfdpost`，填写 ANSYS CFX 的 `bin` 目录。
3. 填写核数、叶片数和流量单位（`kg/s` 或 `g/s`，按 CFD-Post 里实际显示的单位选）。
4. 编辑扫描点表格（见下），点击开始（`F5`）。

每个路径输入框右边的小圆点表示检查结果：绿色正常，黄色提醒，红色错误，灰色表示选填项未填。
悬停可以看到完整路径和说明。相对路径统一以"工作目录"为基准；从资源管理器"复制为路径"得到的带引号路径也能识别。

## 扫描点表格

每一行是一条转速线：转速（rpm）和这条线起始的出口背压（Pa）。

- 双击或按 Enter 编辑；Tab / Shift+Tab 在单元格之间跳转，在最后一行按 Tab 会自动新增一行。
- 可以直接从 Excel 粘贴两列数据；右键可以排序或清空。
- "批量生成…"：按起止转速和步长一次生成多行。
- 无效的行用红色标出。
- `Ctrl+S` 保存成 CSV。表格格式见 [数据格式说明](data_format.md)。

## 开始扫描前的确认

按 `F5` 会弹出确认框，列出本次扫描的范围，并提醒可能的问题，例如：找不到 `cfx5solve`、
基础 CCL 缺少 `MySpeed` 或 `MyBackPressure`、初始背压超过安全上限、转速重复。

## 扫描过程中

- 表格逐行显示"扫描中 / 已完成"；工具栏显示当前转速线和已提取的工况点数；状态栏显示已运行时间。
- 日志按错误、警告、成功分颜色并带时间戳，可复制或保存。
- **终止扫描**按钮会结束 PowerShell 脚本和它的子进程。关闭窗口时若任务还在跑，也会先终止它们。
  终止后如果发现 `solver-mpi.exe` 等 CFX 进程没有跟着退出，会询问是否一并结束。

## 扫描如何推进

对每条转速线，程序从起始背压开始逐点求解，并逐步调整背压以扫过整个稳定范围。
一旦发现流量骤降、堵塞或发散的点，该背压就成为"失败上界"：之后只在"最后一个稳定点"与"最低失败上界"之间
二分细化，不会读取这个区间之外的更高背压历史结果，也不会放宽已经确认的失败上界。

结果每个工况一行写入结果表。表里会记下 `.res` 文件的修改时间和大小，作为"缓存指纹"：
同名 `.res` 被重新求解或覆盖后，脚本会发现指纹变化，自动重新提取并更新原来的那一行。

## 出图

- 点击"绘制压气机图"可随时出图；默认勾选"扫描完成后自动绘图"，扫描成功后自动生成 PNG。
- 喘振线可选拟合方式：二次、一次，或自动选择。
- "绘图压比"可选静压比或静止系总压比（默认静压比），选择会被保存，同时用于手动和自动绘图。
  旧结果缺少总压比列时，需要重新提取。
- 绘图时读取结果表里的叶片数：新结果不会重复乘叶片数；旧结果缺这一列时，按界面里填的叶片数把单流道流量换算成整机流量。
- 完成后可以直接打开图像；"打开"菜单可以快速打开工作目录、结果表、特性图。

## 设置的保存

窗口大小、分栏位置和各项参数（路径、核数、叶片数、流量单位、绘图路径、自动绘图选项等）会自动保存在仓库目录下的
`.cfx_gui_settings.json`，下次启动自动读回。

## 不用界面，直接运行脚本

主扫描脚本 `cfx.ps1` 的参数：

| 参数 | 含义 |
|---|---|
| `-DefFile` | 求解输入文件 |
| `-BaseCclFile` | 基础 CCL 文件 |
| `-InitialResFile` | 可选的初始流场 |
| `-CsvFile` | 结果表输出路径 |
| `-SpeedPressureTablePath` | 扫描点 CSV |
| `-Cores` | 并行核数 |
| `-BladeCount` | 叶片数，用来把单流道流量换算成整机流量 |
| `-MassFlowUnit` | CFD-Post 输出的流量单位，目前支持 `kg/s` 和 `g/s` |
| `-WorkingDirectory` | 工作目录 |

叶片数和流量单位必须由用户明确给出，程序不再尝试从 `.res` 里猜，这样更稳妥。

`data_only.ps1` 可以对目录下已有的全部 `.res` 批量提取结果到 `Extracted_Compressor_Data.csv`：
已经提取且 `.res` 没变化的会跳过，重新提取会覆盖同名记录而不会产生重复行；加 `-Force` 可强制全部重新提取。
